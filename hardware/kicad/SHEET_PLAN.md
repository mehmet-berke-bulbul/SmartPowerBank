# KiCad Hierarchical Sheet Plan

| Sheet | Purpose |
|---|---|
| 01_USB_C_PD | USB-C receptacle, CC lines, ESD, PD controller and configuration support |
| 02_BIDIRECTIONAL_CHARGER | Buck-boost charger, external FETs, inductor, input/output capacitors |
| 03_BMS_PROTECTION | BMS AFE, shunt, protection FETs, balancing, battery safety signals |
| 04_BATTERY_INTERFACE | Pack connector, fuse, service connector, cell-tap connector |
| 05_STM32_CONTROL | STM32, clocks, reset, I²C/SPI, ADC, regulators |
| 06_DISPLAY_UI | OLED, buttons, LEDs/buzzer if used |
| 07_TEMPERATURE_SENSING | Battery NTC, power-stage NTC, analog filtering |
| 08_DEBUG_PROGRAMMING | SWD, UART, boot mode, debug headers |
| 09_TESTPOINTS_AND_SERVICE | Test points, measurement headers, manufacturing/service options |
